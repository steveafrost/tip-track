## Description replacement

> TipTrack Delivery Log is an iPhone app for keeping a usable delivery history.
>
> Save the order ID and delivery address as soon as an order is complete. Choose a tip range now—or update it later when a delayed tip is reported. Search saved orders by number or address, then check repeat locations to review the tip history you recorded there.
>
> **Built for quick, manual logging**
> - Save delivery order IDs and addresses
> - Record a tip range: No Tip, Less Than $5, $5–10, More Than $10, or More Than $20
> - Find a saved order by order ID or delivery address
> - Update delayed tips after a delivery
> - Review tip-range distribution and saved location history
> - Log and update orders with Shortcuts and Siri
>
> Start with 20 free orders. TipTrack Pro is a one-time $4.99 unlock for unlimited order logging, saved location history, and tip-pattern reports—no subscription.
>
> TipTrack is a personal delivery log. It does not connect to delivery-platform accounts or calculate exact payouts, mileage, or earnings.
