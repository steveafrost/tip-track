1. Open the community’s current official rules page while logged into the owner’s real account. The modern JSON rules endpoints returned HTTP 403 `Blocked` from this environment on the same check date; the documented old-Reddit sidebar was used only to read the public rule text.
2. Record the exact self-promotion, spam, account-age, flair, link, and moderator-permission requirements in this file, with the rules URL and check date.
3. If the rules are ambiguous or require permission, contact moderators through the platform and wait for a clear affirmative response. Do not use an alternate account or disguise the app relationship.
4. Publish only an accurate, disclosed post using the approved campaign token `ct=reddit-approved`; then record the public URL in `CAMPAIGN-TRACKER.md`.
